# Suraksha Sonic — Showcase Site

Static site (no build step) for the SIH 2026 pitch/demo.

## Files
- `index.html` — all page content + SEO/meta tags
- `styles.css` — all styling
- `script.js` — hero risk-gauge animation
- `og-banner.png` — social preview image (Open Graph / Twitter Card)
- `robots.txt`, `sitemap.xml` — basic SEO

## Before you publish
Replace `https://surakshasonic.example.com/` in `index.html`,
`robots.txt`, and `sitemap.xml` with your real deployed URL
(e.g. your GitHub Pages / Vercel / Netlify domain).

## Deploy (pick one, all free)
- **GitHub Pages**: push this folder to a repo, enable Pages on the `main` branch.
- **Netlify / Vercel**: drag-and-drop this folder onto their dashboard — no build command needed.
